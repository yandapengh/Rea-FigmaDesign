## 2. 方法

沿用現有 Tier 2 風格分類器：

- 特徵：主字體家族、token 比率、palette Jaccard、圓角 Jaccard
- 權重：字體 0.4 / token 0.35 / palette 0.1 / 圓角 0.15
- 判定：分數差距 < 0.1 → unknown（放棄）
- 驗證：leave-one-out（每個樣本從自己的類別統計中扣除）

## 3. 結果

| 任務 | 樣本 | 嚴格 accuracy | 強制 top1 | 放棄率 | top3 |

| 50 類分類（minor） | 532 | 7/532 = **1%** | 175/532 = **33%** | **97%** | 40% |
| 世代（old/new） | 1,345 | 0/1,345 = **0%** | 375/1,345 = **28%** | **100%** | 100% |

### 對照：顏色＋結構模型（先前驗證）

- 世代任務：人工標註 163 筆上 LOO = **99%**
- 只用結構：93%；只用顏色：99%（權重 3）

結論：**現有風格分類器不足以支撐 30 類與世代任務**；顏色＋結構才是有效訊號。

## 5. 對 Part 2 的意義

1. **Stage 5**：剝洋蔥正規化 + Tier 1.5 鬆弛指紋，先把「同結構不同命名」收斂。
2. **世代**：顏色指紋必須進模型，純風格特徵不可用。
3. **分類**：需要階層（大類 → 小類）與頁面脈絡，不能只用全域風格相似度。
4. **unknown 門檻**：目前 margin 0.1 造成 97% 放棄；Part 2 要重新校準，而不是直接降低門檻。
5. **資料清理**：461 筆衝突需先確認「同一結構是否允許不同標籤」。
